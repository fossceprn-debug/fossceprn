# Contributing to FOSS CEPrn

First of all, thank you for your interest in contributing to FOSS CEPrn!

We welcome contributions from developers, students and open-source enthusiasts who want to help improve the project.

## How to Contribute

You can contribute in several ways:

- Report bugs and issues.
- Suggest new features.
- Improve the user interface and user experience.
- Fix existing issues.
- Improve documentation.
- Submit code improvements.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your changes.
4. Make your changes.
5. Test your changes.
6. Commit and push your changes.
7. Open a Pull Request.

## Development Guidelines

- Follow the existing project structure.
- Write clean and readable code.
- Use meaningful variable and function names.
- Avoid unnecessary dependencies.
- Test your changes before submitting.
- Do not commit passwords, API secrets or private information.

## Pull Requests

When submitting a Pull Request:

- Provide a clear title.
- Explain what you changed.
- Mention any related issues.
- Include screenshots for UI changes when appropriate.
- Make sure the application builds successfully.

## Community

Be respectful, collaborative and open to feedback.

Every contribution, big or small, is appreciated.

Thank you for helping make FOSS CEPrn better!

**FOSS CEPrn — Learn. Build. Share. Contribute.**
